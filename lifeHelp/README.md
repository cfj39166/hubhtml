# 生活小助手 🧰

一个**手机优先**的网页版生活工具箱：干净、离线优先、无广告、无账号，数据全部保存在本机浏览器。按"工具箱 + 生活记录 + 提醒"三合一思路设计，主打"找得快、离线能用、提醒可靠、隐私安全"。

## 快速开始

- **直接使用**：双击打开 `index.html` 即可（`file://` 下全部核心功能可用）。
- **推荐方式**：任意静态服务器打开，例如：

```bash
cd lifeHelp
python -m http.server 8080
# 手机与电脑同一网络时，用 http://电脑IP:8080 在手机上访问
```

- **像 App 一样用**：手机浏览器打开后 → 菜单 →「添加到主屏幕 / 安装应用」，即可全屏离线使用（已内置 PWA 清单与 Service Worker 缓存）。

## 功能总览（28 个工具）

| 分类 | 工具 |
| --- | --- |
| 计算换算 | 计算器（基础+科学+历史）、单位换算（8 类）、日期计算、年龄计算（生肖星座）、房贷计算、个税计算、折扣/满减/AA、大写金额、进制转换、随机决定（随机数/骰子/硬币/抽签）、亲戚称呼 |
| 扫描识别 | 二维码生成、扫码识别（相机/图片） |
| 记录提醒 | 待办清单、备忘录、简单记账、习惯打卡、喝水提醒、吃药提醒、生日纪念日、倒计时/秒表、番茄钟、密码生成器 |
| 健康生活 | BMI 计算（含基础代谢）、垃圾分类、天气查询 |
| 家居出行 | 手电筒（白光/红光/SOS） |
| 学习办公 | 字数统计 |

**框架能力**：四 Tab（首页/工具库/记录/我的）、全局搜索（支持拼音与别名，如 `jsq`、`mima`、`fk`）、收藏置顶、最近使用、场景清单一键导入待办（旅行/搬家/租房检查/开学/春节回家）、深色模式、三档字号（特大即老人模式）、数据导出/导入 JSON 备份、全局提醒引擎（喝水间隔提醒、吃药到点提醒，应用打开时生效）。

## 移动端适配

- 单列手机布局（最大 560px），桌面打开居中显示
- 输入框 ≥16px 防 iOS 聚焦缩放；`touch-action: manipulation` 消除点击延迟
- 安全区适配（刘海屏 `env(safe-area-inset-*)`）、`100dvh` 视口
- 大触控目标（计算器键盘、打卡按钮、勾选框热区扩大）

## 技术说明

- **零依赖、零构建**：原生 HTML/CSS/JS（ES5 兼容写法 + 模板字符串），双击即开
- **工具注册表驱动**：所有工具登记在 `assets/js/registry.js`，首页、搜索、收藏、最近使用、相关推荐全部从注册表读取，新增工具只需一条定义 + 一个渲染函数
- **数据**：localStorage（`lh_` 前缀），支持导出/导入 JSON
- **需联网的工具只有 3 个**：天气（Open-Meteo 免费接口、无需 Key）、二维码生成/扫码（组件首次从公共 CDN 加载后缓存本地，之后离线可用）
- **权限按需**：相机（扫码）、定位（天气）、通知（提醒）均在使用对应功能时才申请

```
│       └── app.js        # 路由 / 四大 Tab / 全局提醒引擎
└── README.md
```

## 已知限制

- 网页无法在**关闭后**后台推送提醒：喝水/吃药提醒在页面（或添加到主屏幕的应用）打开时生效，iOS PWA 限制相同
- 生肖、虚岁按公历年估算；工作日计算不含法定节假日
- 各城市垃圾分类标准略有差异，内置库仅供日常参考
- `file://` 直开时扫码相机、PWA 安装不可用（浏览器安全策略），建议走 http 或添加到主屏幕
