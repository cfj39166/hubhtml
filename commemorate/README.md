# 我们的宇宙 ❤ 有故事线的情侣纪念网页

一个开箱即用的单人份"情侣纪念网站"：星空开场 → 密码锁 → 恋爱计时/数据 → 回忆时间轴 → 照片墙 → 星图足迹 → 心愿清单 → 情书 → 默契问答 → 未来信箱 → 心情打卡 → 彩蛋 → 恋爱报告海报。

纯静态网页，**不需要安装任何东西**，改内容只需要编辑一个文件。

---

## 一、怎么打开

- **本地看**：直接双击 `index.html` 用浏览器打开即可（推荐 Chrome / Edge）。
- **想更流畅**：在本目录运行 `python -m http.server 8000`，然后浏览器访问 `http://localhost:8000`。
- **发给另一半**：部署到任意静态托管（见下文"部署"），把链接发过去。链接默认不被搜索引擎收录（已加 `noindex`）。

> Three.js（3D 爱心）从 CDN 加载，**需要联网**；加载失败会自动降级为 2D 星空，页面依然可用。

## 二、怎么改成你们的内容（只需要改 `js/data.js`）

打开 `js/data.js`，每个字段都有中文注释，照着改即可：

| 想改什么 | 改哪里 |
|---|---|
| 昵称 / 头像表情 / 签名 | `couple.a` / `couple.b` |
| 在一起的时间（计时器起点） | `anniversary`（格式 `2023-05-20T21:00:00`） |
| 访问密码 | `password.value`（还可以设置 `also` 备用密码和 `hint` 提示语） |
| 彩蛋关键词 / 全屏告白文案 | `eggKeywords` / `confession` |
| 情话库（每日情话轮换） | `quotes` |
| 回忆时间轴（故事线） | `events`，每条含日期/标题/故事/城市/第几幕/照片 |
| 照片墙 | `photos`，把真实照片放进 `photos/` 文件夹并填 `src` |
| 星图足迹 | `places`，填城市名 + 经纬度 + 故事 |
| 纪念日倒计时 | `countdowns`，生日/周年用 `recurring: "05-20"` 每年循环 |
| 心愿清单 | `wishes`，`done: true` 表示已完成 |
| 初始情书 / 问答题目 | `letters` / `quiz` |

**照片**：把图片放进 `photos/`（如 `p01.jpg`），在 `photos` 数组里引用。某张照片还没放进去也没关系——网页会自动生成一张与故事线配色匹配的占位插画，页面照样好看。

**背景音乐**：把音乐命名为 `music.mp3` 放进 `assets/` 文件夹，网页会自动优先播放它；没有音乐文件时会播放程序实时生成的星空小曲（无版权问题）。⚠️ 请使用你有权使用的音乐。

## 三、隐藏彩蛋 🥚

- **全屏告白**：在页面任意位置（非输入框）连续敲出关键词，默认 `love` 或双方名字缩写 `acxn`（在 `data.js` 里改）。
- **爱心烟花**：连续点击首页的大爱心 5 次，触发烟花汇演。
- **恋爱报告**：长按首页大爱心（或点"恋爱报告"区块的按钮），生成可保存的长图海报。
- **鼠标拖尾**：移动鼠标会撒下小爱心和小星星。
- **随机回忆**：照片墙的"🎲 随机回忆"按钮随机翻开一张回忆。

## 四、数据保存在哪

- 密码解锁状态：`sessionStorage`（关掉浏览器标签后失效，下次要重新输密码）。
- 心愿勾选 / 网页上新增的情书 / 未来信箱 / 心情打卡：保存在**这台设备的浏览器** `localStorage` 里，换设备或清缓存不会同步。
- 所有"官方内容"都在 `js/data.js` 里——想同步到别的设备，部署同一个 `data.js` 即可。

## 五、部署（分享链接给 TA）

1. **Netlify Drop**（最简单）：打开 [app.netlify.com/drop](https://app.netlify.com/drop)，把整个文件夹拖进去，几秒后得到一个链接。
2. **GitHub Pages**：新建仓库上传这些文件，Settings → Pages 开启。
3. **Vercel**：导入仓库，零配置部署。

隐私建议：链接只发给 TA；页面已自带 `noindex, nofollow`，不会被搜索到。若需更强隐私，可以把部署链接做成不易猜到的子路径，或在 Netlify/Vercel 上加访问限制。

## 六、文件结构

```
├── index.html          页面结构
├── css/style.css       全部样式（星空/玻璃拟态/响应式）
├── js/
│   ├── data.js         ★ 你的"后台"：所有内容都在这里改
│   ├── effects.js      烟花/爱心拖尾/占位插画生成器
│   ├── three-heart.js  3D 粒子爱心 + 星空（Three.js）
│   └── main.js         全部交互逻辑
├── photos/             放你们的照片（可选）
├── assets/             放背景音乐 music.mp3（可选）
└── README.md
```

## 七、常见问题

- **打开是黑屏 / 只有一片星空？** Three.js 从 CDN 加载需要联网；离线时会自动用 2D 星空，功能不受影响。请确认能访问公网，或把 `three.min.js` 下载到本地并修改 `index.html` 里的 `<script src>`。
- **忘记密码？** 打开 `js/data.js` 看 `password.value`（网页输错 4 次后页面也会偷偷提示你）。
- **手机上好用吗？** 已做移动端适配（竖屏布局、触屏滑动翻照片、触屏拖尾爱心）。
- **想加一张时间轴节点？** 在 `events` 数组里照格式加一条，刷新即可。
