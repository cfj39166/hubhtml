设置 / 关于

关于本工具：这是 Qt 桌面 / 安卓原生 App 的网页版原型，用于功能演示和分享。 「生成」功能使用精心设计的示例数据展示最终输出样式，不调用真实 AI。

要接入真实的 AI（智谱 GLM-4.1V 视觉模型生成观察记录、CogVideoX 生成动画），需要一个后端代理 （智谱 API 不允许浏览器直接跨域调用）。技术上不复杂，但需要部署一个小服务。
