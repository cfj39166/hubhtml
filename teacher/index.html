关于 AI 能力

本网页版是原型演示，「生成」功能使用精心设计的示例数据展示最终报告样式。

要接入真实的 AI（智谱 GLM-4.1V 视觉模型），需要一个后端代理转发请求（智谱 API 不允许浏览器直接跨域调用）。技术上不复杂，但需要部署一个小服务。

Qt 桌面/安卓原生版已完整对接真实 AI，本网页版用于功能展示和分享。
