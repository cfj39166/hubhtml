热力图回答一个问题：下一栋开哪栋

108 栋楼不可能一次全开。热力图的作用是给出扩展顺序： 哪栋楼需求高、供给够，就开哪栋；哪栋楼需求高但供给空，就先招服务者再开。

需求高 + 供给够 → 立即开
这类楼栋开一天就能跑起来，是最优先的扩展目标。
需求高 + 供给空 → 先招人
开了也接不住，居民发一次单没人接，这个楼就废了。
需求低 + 供给够 → 先培育
协调人先做地推、先拉需求，供给优势可以等。
