风险分级的三条硬边界

这三条不是配置项，是产品红线
A 类 · 低风险
代取、代扔、借还、遛狗喂猫。个人可接，lv1 即可。不强制协议、不强制保险。
B 类 · 中风险
寄养、上门家政、接送、陪诊、证件代办。必须 lv2 + 强制协议 + 保险生效。
C 类 · 高风险
托育、养老照护、医疗陪护。个人永远不能接，只做机构入口与筛选。
✕
C 类不开放个人接单不是「默认关闭可以打开」的开关，而是写死的产品约束。 社区平台一旦承接了托育、失能照护、医疗行为，就不再是居间方，而是实际服务提供方 —— 资质、消防、食品安全、人员背景审查全部落到平台头上，这是不可能的。

必填字段为什么按品类不同

字段设计的目标只有一个：让纠纷发生时，双方都拿得出证据。 所以字段不是「越多越好」，而是「缺了它就无法判定责任」的那些才必须填。

取件码脱敏（A1）：服务者只需知道后四位，不需要知道完整码 —— 减少被冒领风险
包裹来源声明（A1 / B5）：这是违禁品拦截的第一道口，不勾选不能提交
宠物健康 + 用药 + 医疗费用上限（B1）：宠物突发疾病时，服务者有权在授权额度内送医
家长确认码（B3）：接送交接的唯一凭据，没有它就无法证明孩子交给了谁
固定路线（B3）：偏离路线的行为可被识别，这是未成年保护的基础
