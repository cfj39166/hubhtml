为什么这些能力必须「公共」

信任标识、信用分、证据链这些东西，如果每个端各做一套，会出现最糟糕的情况： 用户端显示「社区信赖」，服务者端显示「平台认可」，后台显示「等级 3」—— 三套口径对不上，纠纷时谁都说不清。

!
公共能力的定义是：只有一套数据源、一套规则、一套展示口径，四个端都是它的消费方。 这也是为什么它单独成一节，而不是塞进某个端里。

公共能力的三个层次

第一层 · 信任可视化（X01 / X02）
三层信任标识 + 双向信用分。作用是把「能不能信」这件事变成用户一眼可判断的信息。 没有这一层，100 栋楼的陌生人场景根本无法开放服务。
第二层 · 风险硬约束（X03 / X04 / X05 / X06）
红线拦截 + 三个专项流程（宠物 / 接娃 / 包裹）。 作用是把「不可逆的风险」挡在发生之前 —— 这类风险一旦发生，事后怎么赔都无法挽回。
第三层 · 平台自保（X07 / X08 / X09 / X10）
证据链 + 权限分级 + 资金冻结 + 小程序载体。 作用是让平台在纠纷中能举证、在内部能防滥用、在交易上能兜底。这是「居间方」定位的技术基础。
